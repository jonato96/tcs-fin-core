# Backend Java Microservices

Arquitectura de microservicios con Spring Boot para gestión bancaria.

## Microservicios
- **ms-clientes** → Gestión de Personas y Clientes
- **ms-cuentas** → Gestión de Cuentas y Movimientos

## Tecnologías
- Java 17 + Spring Boot 3
- PostgreSQL
- RabbitMQ
- Docker / Docker Compose
- Maven

## Requisitos
- Java 17+
- Docker y Docker Compose
- Maven 3.8+

## Levantar el proyecto
```bash
docker-compose up --build
```
